## 一、 eDPI 科学换算公式与职业选手的黄金区间模型

许多新手玩家为了“转头快”将灵敏度调得极高，结果在微调瞄准时准星乱晃点不到头，进而去卡盟寻找自瞄外挂。
在真正的职业电竞领域，灵敏度存在一套标准化的测量单位——**eDPI（有效每英寸点数）**：
`eDPI = 鼠标物理硬件 DPI × 游戏内灵敏度 (Sensitivity)`
- **职业选手 eDPI 分布常模**：通过对 HLTV 现役 Top 100 职业选手的配置统计，其 eDPI 中位数稳定在 **750 ~ 880** 之间；
- **低 eDPI 的物理优势**：低灵敏度（例如 400 DPI × 2.0 = 800 eDPI）允许玩家利用整条小臂完成大范围转身，而利用手腕与手指完成像素级微调定位，大幅拓宽瞄准容错率。

| 鼠标硬件 DPI | 游戏内灵敏度 | 最终 eDPI | 定位操控风格与适用场景 |
| :--- | :--- | :--- | :--- |
| 400 DPI | 1.8 | 720 eDPI | 极致稳定慢准星 (适合架点主狙与大臂定位) |
| 800 DPI | 1.0 | 800 eDPI | 现代职业选手最主流黄金配置 (兼顾拉枪与微调) |
| 1600 DPI | 0.55 | 880 eDPI | 超低输入抖动，极度细腻平滑跟随传感器 |
| 3200 DPI | 1.5 | 4800 eDPI (错误) | 极度畸形，手指轻微脉搏跳动即导致准星飘走 |

## 二、 消除 Windows 底层鼠标加速与输入抖动实操

要实现纯粹的 1:1 绝对线性鼠标跟踪，必须排查系统端干扰：
1. 打开控制面板 -> 鼠标属性 -> 指针选项 -> **务必取消勾选“提高指针精确度”**！该选项本质是 Windows 自带的非线性鼠标加速，移动越快指针移动距离成倍膨胀，会彻底毁灭拉枪的肌肉记忆；
2. 将指针移动速度严格保持在 **第 6 格（默认中间位置）**，确保系统对鼠标原始输入数据不做任何加权插值或丢弃。
